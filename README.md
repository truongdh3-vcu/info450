# INFO 450: Information Systems Development

## Overview
Welcome to **INFO 450** at Virginia Commonwealth University (VCU). This course serves as a capstone-level experience focusing on system design, software development methodologies, architecture, and full-stack application construction. 

---

## Course Details
* **Course Code:** INFO 450
* **Title:** Information Systems Development
* **Institution:** Virginia Commonwealth University (VCU)
* **Department:** Information Systems / School of Business

---

## Key Topics Covered
- **Software Development Lifecycle (SDLC):** Agile, Scrum, and Iterative Development
- **Full-Stack Web & Software Development:** Frontend UI/UX, Backend APIs, and Integration
- **Database Systems:** Relational design (SQL), ORMs, and persistent data storage
- **System Design & Architecture:** UML diagramming, component modeling, and API integration
- **Version Control & Collaboration:** Git workflows, branching strategies, and collaborative GitHub repositories
